# Encanto Véline - E-commerce de Lujo 👙

Este es un proyecto de tienda virtual de lencería diseñado para ofrecer una experiencia de compra premium y fluida.

## 🔗 Demo en Vivo
Mira la tienda funcionando aquí: 
👉 [https://catalogoencantoveline.netlify.app/](https://catalogoencantoveline.netlify.app/)

## 🚀 Características Principales
* **Catálogo Dinámico:** Gestión de múltiples productos con descripciones y precios.
* **Experiencia Visual:** Implementación de un visualizador de imágenes (Zoom/Lightbox) para ver detalles de las prendas.
* **Conversión Directa:** Botón de pedido que conecta directamente al cliente con WhatsApp.
* **Diseño Responsivo:** Optimizado para que las clientas compren desde su celular sin problemas.

## 🛠️ Tecnologías
* HTML5 / CSS3 (Efectos de transparencia y sombras dinámicas)
* JavaScript moderno para la interactividad.
* Vite como herramienta de construcción rápida.
